# mmo-rpg
## Этап 3: Паттерн создания юнитов

Для создания персонажей был выбран паттерн **«Фабричный метод» (Factory Method)** вместо «Абстрактной фабрики».

### Почему именно он:

1. **Деление по ролям, а не по фракциям:**
   В игре персонажи разделены по ролям (`Carry`, `Midder`, `Support`), а не по лагерям (например, Свет и Тьма). Под каждую роль логично иметь свою отдельную фабрику (наши `CarryFactory`, `MidderFactory`, `SupportFactory`), которая создаёт бойцов нужного типа.

2. **Легко добавлять новые роли:**
   Если в игру понадобится добавить новую роль (например, `HardLiner`), достаточно создать класс `Hard` и для него `HardFactory`. Код игрового поля и базовой фабрики менять не придётся.

3. **Поле не знает о конкретных героях:**
   Игровое поле `GameField` работает только с базовым классом `UnitFactory` и возвращает базовый указатель `std::unique_ptr<Unit>`. Поле не привязано к коду конкретных персонажей.
